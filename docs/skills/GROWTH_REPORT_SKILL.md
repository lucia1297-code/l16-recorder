# 스킬: 상담평가서 (발전기록) 작성 기준
> 작성일: 2026-08-28 | L16 개인 영어 지도

---

## 작성 원칙

### 1. 대상 및 목적
- **대상**: 학부모 (학생 본인 아님)
- **목적**: 학생의 현재 수준 + 미래 방향 + 강사의 전문적 판단 전달
- **발송**: 매월 10일 정기 발송 또는 "작성" 지시 시

### 2. 문체 기준
- **정중하고 전문적인 경어체** ("~하고 있습니다", "~드립니다")
- 학부모를 존중하는 어투 ("안녕하십니까", "감사드립니다")
- 단정적 단언 금지 → 가능성과 방향 제시
- 학생 이름 호칭: "○○ 학생은" / "○○ 학생의 경우"

### 3. 구성 (10줄 기준)
```
1줄: 인사 + 이달 학습 기간 언급
2줄: 현재 실력 수준 + 점수 추이 (구체적 수치)
3줄: 주요 오답 원인 분석 (전문적 용어)
4줄: 오답 원인의 근본 이유 (독해력/어휘력/논리력)
5줄: 학생 자가 회고 요약 (어려웠던 점, 목표)
6줄: 강사의 전문적 진단
7줄: 단기 처방 (이번 달 집중 과제)
8줄: 중기 전략 (1~2개월 방향)
9줄: 미래 목표 제시 (수능까지 로드맵)
10줄: 격려 + 학부모 협조 요청
```

### 4. 금지 표현 (무성의한 표현)
- ❌ "수고했습니다. 화이팅"
- ❌ "어휘 암기 하루 30개"
- ❌ "마지막 5분 선지 재확인"
- ❌ 단순 나열형 처방
- ❌ 이모지 과다 사용

### 5. 권장 표현 (전문적 표현)
- ✅ "핵심어 중심 독해 전략을 강화하는 방향으로 지도하고 있습니다"
- ✅ "추론형 문항에서의 실점은 지문의 논리 구조를 파악하는 훈련으로 개선 가능합니다"
- ✅ "현재 수준에서 목표 점수까지의 간격을 고려할 때, 어휘 기반 독해력 강화가 가장 효율적인 경로입니다"
- ✅ "수능 영어 1등급 기준(90점)을 목표로, 현재 취약 영역을 체계적으로 보완해나가고 있습니다"

### 6. 점수대별 평가 기준
| 점수대 | 등급 | 평가 방향 |
|--------|------|-----------|
| 90↑ | 1등급 | 안정적 유지 + 실전 전략 정밀화 |
| 80~89 | 2등급 | 취약 유형 집중 + 1등급 진입 전략 |
| 70~79 | 3등급 | 독해력 기반 강화 + 어휘 체계화 |
| 60~69 | 4등급 | 기초 어휘 + 문장 구조 파악 |
| 60↓ | 5등급↓ | 기초부터 재정비 + 학습 습관 형성 |

```
이달 ○월 동안 ○○ 학생의 수업 및 학습 현황을 아래와 같이 정리하여 말씀드립니다.

[현재 수준]
(점수 추이 + 변화 + 등급 언급)

[오답 분석]
(원인별 전문적 분석 + 근본 이유)

[학생 회고]
(학생 자가 평가 + 강사 해석)

[강사 진단]
(전문적 소견)

[처방]
(단기: 이번 달 / 중기: 1~2개월)

[미래 목표]
(수능까지 로드맵)

[마무리]
(격려 + 학부모 협조 요청)
```
